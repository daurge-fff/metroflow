MetroFlow — минималистичный симулятор и конструктор системы метрополитена на
Rust и [Macroquad](https://macroquad.rs/). Карта, станции, линии, поезда и
интерфейс рисуются векторно, без растровых ассетов.

Автор — **German Vitiaz** ([@daurge](https://t.me/daurge) · [GitHub](https://github.com/daurge-fff)).

## Возможности

- **Процедурная генерация карт**: «Новая симуляция» открывает окно параметров
  (станции, линии, узлы, поезда на линии) с кнопками «Случайная» и «Создать»;
  параметры валидируются.
- **Демонстрационная сеть** из 4 линий и 10 станций и **конструктор своей карты**
  с нуля.
- **Редактор**: инструменты «Выбор / Станция / Ветка / Удалить», перетаскивание
  станций, **перестановка станций внутри маршрута** (тянуть вдоль активной
  линии), объединение и переименование, отсоединение линий, создание и удаление
  маршрутов, цвет и стиль, отмена и повтор.
- **Пассажиры с маршрутами и пересадками**: пункт назначения, выбор линии по
  времени в пути с учётом штрафа за пересадку (эскалаторы), посадка только в
  подходящий поезд.
- **Поезда**: непрерывное движение, остановки, развороты, индикатор посадки,
  **авто-состав** (число вагонов по загрузке) и **несколько поездов в одном
  направлении** (мин/макс на направление, авто по загрузке).
- **Автосохранение**, **рост сложности по дням** и **расширение сети** новой
  веткой из редактора.
- **Суточный цикл** и **час пик**: освещённость и пассажиропоток зависят от
  игрового времени.
- **Настройки**: интерфейс, состав поездов (мин/макс вагонов, вместимость
  вагона, авто-состав), поезда в одном направлении, уровень и рост
  пассажиропотока, **масштаб интерфейса**, автосохранение, язык.
- **Мобильная сборка (Android)**: полный экран, ландшафт, крупный интерфейс.
- **Аналитика в реальном времени**: KPI, графики (очереди, ожидание,
  пропускная способность), таблицы линий и загруженных станций.
- **Карта**: подсказка над станцией, режимы «Нагрузка станций» и «Поток по
  линиям», стрелки потока, тепловая подсветка, тревоги по перегрузке.
- **Сохранение и загрузка** с версией формата и проверкой целостности.

## Требования

- Rust **1.82+**.
- macOS: инструменты командной строки Xcode (`xcode-select --install`).
- Linux: пакеты X11/OpenGL (например, `libx11-dev libxi-dev libgl1-mesa-dev`).

## Установка Rust

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

## Запуск

```sh
cargo run --release
```

Готовый бинарник: `target/release/metroflow`.

Сборка под Windows/Linux/Android и упаковка `.app`/APK — в
[docs/BUILDING.md](docs/BUILDING.md).

```sh
cargo fmt --check
cargo clippy --all-targets
cargo test
cargo build --release
```

## Управление

**Мышь:** клик по станции — выбрать; перетаскивание — панорама (с инерцией);
колесо — зум к курсору.

**Клавиатура:**

| Клавиша    | Действие                                  |
| ---------- | ----------------------------------------- |
| `Пробел`   | пауза / продолжить                        |
| `1`…`5`    | скорость ×1 / ×2 / ×4 / ×8 / ×16          |
| `+` / `-`  | приблизить / отдалить                     |
| `F` / `C`  | вписать сеть / центрировать               |
| `L` / `G` / `W` | подписи / сетка / пассажиры          |
| `H`        | справка                                    |
| `Esc`      | меню (в настройках — назад)               |

**Панель управления картой** (снизу слева): зум, вписать, центрировать,
подписи, сетка, пассажиры, анимации, «Нагрузка станций», «Поток по линиям»,
справка. **Аналитика** — кнопка-график в верхней панели. **Редактор** — кнопка
с карандашом.

## Архитектура

Модульная структура, симуляция не зависит от отрисовки. Подробнее —
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
src/
├── main.rs        # окно и цикл кадра
├── lib.rs         # публикация модулей
├── geom.rs        # 2D-геометрия
├── app/           # сцены, ввод, редактор, цикл
├── camera/        # мировые/экранные координаты, зум, инерция
├── config/        # палитра, шрифты, настройки
├── network/       # станции, линии, маршрутизация
├── simulation/    # время, поезда, пассажиры
├── render/        # векторная карта, примитивы, текст
├── save/          # сохранение/загрузка
└── ui/            # панели, меню, редактор, аналитика, иконки
```

## Формат сохранений

JSON с номером версии. Проверяются версия, целостность сети и согласованность
симуляции. Расположение (crate `directories`):

- macOS: `~/Library/Application Support/app.MetroFlow.MetroFlow/`
- Linux: XDG-каталог данных
- Windows: `%APPDATA%\MetroFlow\MetroFlow\`

```
saves/quicksave.json   # состояние симуляции
settings.json          # настройки
```
